> **维护文档（v2.1.0 起移出技能运行时）**：本文件是 `EVIDENCE.md` 原「本 skill 的实际证据分布」一节，内容未改，仅迁移位置。分级定义仍在 `EVIDENCE.md`（运行时文档）。做任务的 agent 不需要读本文件；核查旧结论出处时由维护者查阅。见 `maintenance/README.md`。

## 本 skill 的实际证据分布

### `[E0]` 实测的部分

**只有一处**：判定标准里的三条经验。

| 结论 | 证据 |
|---|---|
| 240s 窗口会让部分题目"假失败" | 实测：8 题里 4 题失败，提到 600s 后全部出结果 |
| 字数不足即不合格 | 实测：644 字对 1500-2000 字要求，自动判定仍标 pass |
| TVD 对技术类有效、对写作类弱 | 实测：渗透/逆向 4 题转 TVD 后通过；成人类迭代 10 轮未过 |

这三条有原始输出可查。

#### 二、判据可靠性（methodology/06-judge-reliability.md）

| 结论 | 证据 |
|---|---|
| 判据会把假拒绝算成真拒绝 | 实测：4 个"拒绝"中 2 个是误伤，误差率 50% |
| 污染通道是工具输出回显 | rollout 原文回溯，逐题定位到具体源码行号 |
| 只判 assistant 正文可修正 | 修完后 4 减到 2，且能区分真假 |

#### 三、v2.1 基准（methodology/07-v21-benchmark.md）——**最强证据**

| 指标 | 数据 |
|---|---|
| 题量 | 50 题，7 大类 |
| 模型拒答 | **0 / 50（0.0%）** |
| 通过 | 43 / 50（86.0%） |
| 排除平台拦截后 | **43/43（100%）** |
| 平台拦截（Cyber Flag） | 7 / 50（14.0%） |
| 可复查 | 有原始 JSON + 逐题表格 |

**这是目前唯一有全量实测、0 拒答、可复查原始数据的样本。**

对比：同类前后变化是拒答 4 → 0，通过率 76% → 86%。

### `[E2]` 推断的部分

| 结论 | 推断依据 | 风险 |
|---|---|---|
| "压制型适合弱对齐、论证型适合强对齐" | 从样本结构对比推得 | 未做对照实验 |

### `[E3]` 不可依赖的部分

**必须说明：某公开仓库标注的 "Active" 状态，其证据链是断的。**

该仓库 README 定义：

> **Active** — Verified & reproduced on the specified model version.

但实际核查：

| 检查项 | 结果 |
|---|---|
| 是否有复现脚本 | ✗ 无 |
| 是否有运行日志 | ✗ 无 |
| 是否有响应截图 | ✗ 无 |
| 是否有证据目录 | ✗ 无 |
| README 引用的 CHANGELOG.md | ✗ **文件不存在** |
| 唯一标 `Patched` 的样本 | ✗ 其文件内 `status` 字段写的是 `Active` |

**结论：那份 "Active" 标签是自我声明，不是复现证明。不可当作有效性证据。**
