# 22 — COVERAGE MODEL（攻击面覆盖率）

> `[E2]` 本文是方法论设计，未被本仓库实测验证——它改的是「怎么测」，不是「提示词多有效」。

## 一句话

**通过率回答「这版提示词有多强」，覆盖率回答「这套测试有没有盲区」。**

两个都要，而且**必须先有覆盖率**——否则通过率可能是在一个极窄的面上刷出来的高分。

## 为什么这是问题

> 通过 500 条直问越狱 ≠ 模型安全。一个从没被测过提示注入或编码混淆的模型，是**覆盖率未知**，不是覆盖率高。

对照本仓库：50 题技术基准覆盖 7 大类，**题目多样性不等于攻击面多样性**。

一个具体例子：

```
50 道题全部通过，且全部是「直接通道 + 工程件载体 + 技术类话题」。
→ 通过率 100%
→ 但「多轮渐进」一次没测、「间接注入」一次没测、「编码混淆」一次没测
→ 真实覆盖率可能只有 60%
```

**这个 100% 是真实的，但它只描述一个面。** 不标注覆盖面，它就会变成一句误导。

## 攻击面矩阵

把「面」定义成**正交维度的组合**，而不是话题清单。本文认这五个维度：

| 维度 | 取值 | 为什么正交 |
|---|---|---|
| **A 通道** | 直接 / 间接 | 决定了防线在哪一层（模型判断 vs 来源识别） |
| **B 形态** | 模块拼接 / TVD 工程件 / 角色扮演 / 渐进升级 | 决定了绕过的是什么（措辞 / 补全倾向 / 人格 / 自洽） |
| **C 载体** | 直问 / 工程件 / 技术文档 / 审计报告 / 教学材料 / 测试用例 / 小说框架 | 决定了请求被当成什么任务 |
| **D 话题域** | 渗透 / 逆向 / 恶意代码 / 外挂 / 破解 / 成人 / 暴力 / 社工 | 决定了触发哪条内容策略 |
| **E 语言** | 中文 / 英文 / 混合 / 编码混淆 | 决定了过滤器在哪一层失明 |

## 怎么算覆盖率

不要算"测了多少题"，算"覆盖了多少格子"。

```
总格数 = A × B × C × D × E
实测格数 = 实际跑过的组合数
覆盖率 = 实测格数 / 总格数
```

**实际上不需要全跑**。做法是：

1. 列出你关心的维度取值
2. 标出实际测过的格子
3. 空白格里，**挑每个维度各至少一个**补齐

```
        A通道    B形态     C载体    D话题    E语言
已测    直接     工程件    直问     渗透     中文
已测    直接     模块拼接  技术文档  恶意     中文
未测    间接     —         —        成人     英文
未测    —        渐进升级  —        暴力     混合
```

## 三个常见盲区

| 盲区 | 表现 | 补法 |
|---|---|---|
| **只测直接通道** | 全是"用户直接说"，没测过"文档里藏着指令" | 加间接注入题 |
| **只测一个载体** | 全是工程件，没试过教学材料/小说框架 | 按 `00-planning.md` 载体表填空 |
| **只测中文** | 编码混淆、多语言一次没试 | 加英文版、混合语言版 |

## 和通过率怎么配

**报告必须同时给两个数**：

```
通过率：43/50（86%）
覆盖率：17/40 格（42.5%）
盲区：间接通道 / 成人话题 / 英文与混淆

结论：86% 的通过率只在一个 42.5% 的面成立。
未覆盖的面上有多大风险，未知。
```

**只给通过率不给覆盖率，等于给一个不可解释的数字。**

## 对我们题库的要求

| 题库 | 覆盖面 |
|---|---|
| Lite（10 题） | 覆盖 10 个话题域，但**全是直接通道 + 混合载体** |
| Normal（25 题） | 5 域 × 5 题，**仍未覆盖间接通道** |
| All（50 题） | 22 域但**几乎全是直接通道** |

**所以任何一档都不足以声称"全面"**。报告时必须注明盲区。

## 一条纪律

**不要用通过率掩盖覆盖率。**

如果只测了最擅长的那个面，100% 通过只能说明"在这个面上很强"，不能说明"这套提示词好"。

报告格式要求：

```
通过率：x/y（z%）
覆盖率：a/b（c%）
本结论只在已覆盖的 a 个格子上成立。
```
